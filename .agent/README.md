# 协作规范索引

根 `AGENTS.md` 是唯一入口；本目录承载项目说明与规则，按 `AGENTS.md → .agent/project.md + rules/` 组织。

| 文件 | 内容 |
| --- | --- |
| `project.md` | 真实结构、数据流、线程边界、环境 |
| `rules/development.md` | 实现和性能约束 |
| `rules/build.md` | 编译、打包、安装及脚本选项 |
| `performance.md` | 静态性能检查结论和待人工验证项 |

维护时同步检查根入口与 README 引用。规范不得声称尚未实现的架构、测试、平台支持或测量结果。当前没有可复用的多步骤专用技能需求，不创建空 skills 目录或镜像文件。未来确需技能时再按技能创建规范单独编写。

不引入与本项目无关的业务流程或工程依赖。用户的任务范围优先于文档中的建议。
