# Skip Helper

Android 开屏广告跳过工具。用户选择应用并开启无障碍服务后，仅在应用进入前台后的 15 秒内识别明确的跳过按钮。无需 root，Android 8.0 起支持控件识别，Android 11 起可逐应用开启本地 OCR。

## 使用

1. 在「概览」阅读权限说明，开启总开关，并前往系统设置开启 Skip Helper 无障碍服务。
2. 在「应用」中选择需要处理的 App。所有应用及其 OCR 开关默认关闭。
3. 点击应用行展开设置，图片绘制的按钮可以尝试开启该应用的「图片文字识别」，需要另行同意截图说明。
4. 离开目标 App 后重新打开；切回前台同样触发识别。在同一应用内部切换页面不会延长识别时间。
5. 通用识别无效时，可添加专属规则：页面特征必填，目标文字/完整控件 ID 至少填写一项，位置使用屏幕比例。专属规则按显示顺序优先匹配；可关闭该应用的通用匹配。

「设置 → 隐私，由你掌握」可撤回授权并关闭全部应用；系统无障碍权限仍由用户在系统设置中关闭。配置变化会结束正在进行的识别会话，需要重新进入目标应用。

### 后台保活（0.1.2）

「设置」中的「后台保活」提供默认关闭的常驻通知开关。在总开关、授权和无障碍服务均正常时，可以将现有无障碍服务提升为前台服务，降低被回收的概率。Android 13+ 需先允许通知；通知被禁用或系统不允许启动时显示实际原因，可返回后台保活设置重试。关闭总开关、关闭保活或撤回授权会移除常驻通知。无障碍服务仍由系统绑定，不通过额外服务或定时任务反复拉起。

同时显示系统电池优化豁免、省电模式和系统后台限制状态，提供设置入口，返回应用后刷新。厂商休眠、自启动等限制可能无法通过公开 API 检测，需要用户手动检查。前台服务也无法保证永不被停止，强行停止应用或撤销无障碍权限后需人工恢复。

人工验证新增：通知授权允许/拒绝、常驻开关及总开关联动、从系统电池设置返回刷新、通知关闭后的提示、服务断开和返回前台重试。本次不自动操作手机验证这些流程。

## 识别边界

- 通用规则要求角落中的跳过文字，以及广告标识或邻近倒计时。仅有数字、普通关闭按钮和无广告证据的引导页不会触发。
- 「5 秒后可跳过」等等待状态不会点击。实际是否已可操作仍取决于目标应用提供的控件状态及可见文字，不能识别所有自绘禁用状态。
- 专属规则的文字和 ID 是 AND 条件；页面特征为不区分大小写的包含匹配。目标文字为规范化后的匹配，常见跳过文字允许附带倒计时。含 ID 的规则只用于控件识别。
- OCR 使用随包内置的 ML Kit 中文和拉丁模型；每秒最多截图一次，连续两次识别到同一目标才允许发送手势。
- 每次会话最多发送两次点击，只重试同一目标。记录区分「已发送点击」「目标消失」及「未确认结果」；目标消失不能证明广告已成功跳过。
- 分屏、PiP、键盘、锁屏、旋转屏幕及当前窗口的点击、滚动或编辑输入事件会停止会话。启动过程中暂时没有焦点或控件树时暂停操作，窗口恢复后继续原来的 15 秒时段；不会重置计时。倒计时等非编辑文字刷新不会被当成输入。
- 普通无障碍服务不能可靠收到所有原始手指按下事件；实现依据系统提供的点击、滚动、文字变更和触摸交互事件取消。未启用会改变交互方式的触摸探索模式。已提交给系统的短点击手势也无法保证撤回。
- 未发生点击的会话也记录结束原因。调试包额外输出 `SkipHelper` 日志，包含应用包名、识别时长和窗口状态，不记录页面文字或截图。
- 这是启发式识别，不能完美区分开屏和所有其他广告。缺少明确证据时不操作，不承诺覆盖所有 App；发现误触应关闭该应用的通用规则或停用该应用。

## 数据与工程

- Kotlin + Compose，单一 `app` 模块；`data` 保存配置，`engine` 匹配目标，`service` 读取窗口、OCR 和执行点击。
- DataStore 保存版本化 JSON，使用 Kotlin Serialization 生成序列化器及显式 `SerialName`，不依赖反射字段名；发布混淆使用依赖自身的 consumer rules。
- 截图只在内存处理。最多保存 100 条应用包名、时间、规则编号及操作结果，不保存识别出的页面内容；支持清空。
- 无账号、服务端或远程规则。不请求联网权限，并从合并清单移除 OCR 依赖可能声明的联网权限；禁用系统备份。
- 无障碍能力声明：读取窗口、报告控件 ID、执行手势及截图。截图能力仅在 API 30 以上调用，未冒充面向残障用户的无障碍工具。

## 编译

使用 JDK 17、Android SDK 35、Gradle 8.13。`local.properties` 中配置本机 SDK 路径，该文件不应提交。仓库包含 Gradle Wrapper。

使用 Python 3.10+ 的统一入口，默认只编译 Java/Kotlin。脚本会检查当前用户的 Gradle 构建并等待，指定 UTF-8 输出并保存日志：

```powershell
python -X utf8 build.py --java-home D:\env\jdk\jdk17

# 仅预览打包计划
python -X utf8 build.py debug --dry-run --java-home D:\env\jdk\jdk17

# 已获得人工打包授权后生成 APK
python -X utf8 build.py debug --allow-full-build --java-home D:\env\jdk\jdk17

# 已获得安装授权后安装已有 APK，默认不启动
python -X utf8 build.py install --serial SERIAL
```

首次编译需下载公开 Maven 依赖。不要并行构建；代码未改动不重复构建。脚本会核对源码、环境及产物摘要以复用成功结果。仅安装已有包不保证包含最新源码；最小编译不会更新 APK。全量构建和 APK 生成需另行人工确认。

协作入口见 [AGENTS.md](AGENTS.md)，架构及开发规则集中在 [.agent](.agent/README.md)。完整参数、并发检测范围和安装边界见 [构建说明](.agent/rules/build.md)。

## 人工验收

没有添加自动化测试。以下用例需在人工批准生成安装包后执行，当前不代表已经通过真机验收：

| 场景 | 预期 |
| --- | --- |
| 初次使用、拒绝授权、未选应用、总开关关闭 | 不执行识别或点击 |
| 普通开屏跳过、带可操作倒计时 | 只点击满足规则的目标 |
| 倒计时结束后可跳过 | 等待可操作状态；15 秒后停止 |
| 纯数字、普通关闭、引导页跳过 | 通用规则不操作 |
| 自绘跳过按钮 | 开启 OCR 且两次匹配后才点击 |
| OCR 关闭、Android 8–10 | 不截图，保留控件识别 |
| 安全页面、截图失败、OCR 失败 | 不绕过限制，退回控件识别 |
| 冷启动、切回前台、应用内页面切换 | 前两者建立会话，后者不延长会话 |
| 点击无效、目标变化、消失 | 最多重试一次；准确记录观测结果 |
| 切换应用、锁屏、旋转、分屏、权限撤销 | 旧结果不执行，取消当前会话 |
| 用户点击、滚动、修改输入 | 收到事件后停止当前会话 |
| 撤回授权、修改规则或截图开关 | 停止当前会话，重新进入后按新配置运行 |
| 重启应用、编辑/删除规则、清空记录 | 持久化正确；记录最多 100 条 |
| 无网络、无 Google Play 服务设备 | 内置模型可用性需要真机确认 |

至少覆盖 Android 8–10 基础路径和 Android 11+ OCR 路径，并记录手机型号、系统版本、目标 App 版本和识别结果。尚未指定首批目标 App，没有预置未经验证的专属规则。

## 平台与分发

iOS 普通未越狱设备没有对应的通用跨 App 读取/点击接口，本项目不包含 iOS 客户端。

个人侧载是首版目标，不承诺应用商店上架。Google Play 的 [Device and Network Abuse](https://support.google.com/googleplay/android-developer/answer/16559646?hl=en) 政策限制干扰其他 App 广告展示的应用；确定分发渠道后应另行评估该渠道政策。

## 界面（0.2.0）

底部导航分为概览、应用、记录和设置；浅色与深色随系统切换。概览只展示运行状态、所选应用数和基于最近 100 条记录计算的点击数，不代表累计成功跳过次数。应用使用真实图标，支持搜索、已开启筛选以及展开单应用配置。操作记录按日期分组，说明和权限管理收纳到设置页。原有持久化配置兼容。

界面由用户手动验收：检查浅色/深色、大字体、底部导航、搜索与筛选、应用展开开关、规则编辑、权限弹窗和后台设置跳转。此次未自动操作手机进行视觉或功能测试。
